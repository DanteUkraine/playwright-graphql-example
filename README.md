# Playwright-graphql example
This is playwright-graphql project template.

As a System under test is https://graphql-pokeapi.vercel.app playground (GraphQL endpoint is https://graphql-pokeapi.graphcdn.app).

### Install dependencies
`npm i`

### Generate graphql schema, operations and types
`./node_modules/.bin/playwright-graphql --url https://graphql-pokeapi.graphcdn.app --coverage`

### Run tests
`npm test`
